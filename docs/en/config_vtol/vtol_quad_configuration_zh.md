# 通用标准 VTOL（QuadPlane）配置与调参

本文档介绍[通用标准 VTOL](../airframes/airframe_reference.md#vtol_standard_vtol_generic_standard_vtol) 的配置，该构型也称为“QuadPlane VTOL”。
它本质上是在固定翼飞行器的基础上增加了四旋翼电机。

有关特定机架的文档和组装说明，请参阅 [VTOL 机架组装](../frames_vtol/index.md)。

## 固件与基本设置

1. 启动 _QGroundControl_。
2. 刷写当前发布版本的固件，或 master（PX4 `main` 分支构建）的固件。
3. 在[机架设置](../config/airframe.md)中选择合适的 VTOL 机架。

   如果列表中没有你的机架，请选择[通用标准 VTOL](../airframes/airframe_reference.md#vtol_standard_vtol_generic_standard_vtol) 机架。

### 飞行/转换模式开关

应在遥控器上分配一个开关，用于在多旋翼模式和固定翼模式之间切换。

::: info
虽然 PX4 允许在没有遥控器的情况下飞行，但在对新机架进行调参和配置时必须配备遥控器。
:::

可在[飞行模式](../config/flight_mode.md)配置中完成此设置，将[飞行模式及其他功能分配](../config/flight_mode.md#what-flight-modes-and-switches-should-i-set)给遥控器上的开关。
也可以使用参数 [RC_MAP_TRANS_SW](../advanced_config/parameter_reference.md#RC_MAP_TRANS_SW) 分配该开关。

开关处于关闭位置时，飞行器以多旋翼模式飞行。

### 多旋翼/固定翼调参

首次尝试转换到固定翼飞行之前，必须确保 VTOL 在多旋翼模式下已经充分调好。
其中一个原因是：如果转换过程中出现问题，飞行器会返回此模式，而此时它可能已经具有相当高的速度。
如果多旋翼模式没有调好，可能会产生严重后果。

如果有可用跑道且飞行器总重量不太大，还应预先完成固定翼飞行的调参。
否则，只能在飞行器切换到固定翼模式后尝试调整。
如果出现问题，必须做好准备，并且能够切回多旋翼模式。

请按照相应的调参指南分别调整多旋翼和固定翼。

### 转换调参

虽然这类飞行器看似只有两种飞行模式（用于垂直起降的多旋翼模式和用于向前飞行的固定翼模式），但实际上还有一个需要调参的状态：模式转换。

正确调整转换过程对于安全进入固定翼模式非常重要。例如，如果转换时空速过低，飞行器可能失速。

#### 转换油门

参数：[VT_F_TRANS_THR](../advanced_config/parameter_reference.md#VT_F_TRANS_THR)

前向转换油门定义了前向转换过程中推式/拉式电机的目标油门。

该值必须足够高，以确保飞行器能够达到转换空速。
如果飞行器配有空速传感器，可以增大此参数以更快完成前向转换。
首次转换时，宁可将该值设置得偏高，也不要偏低。

#### 前向转换推式/拉式电机油门变化速率

参数：[VT_PSHER_SLEW](../advanced_config/parameter_reference.md#VT_PSHER_SLEW)

前向转换是指从多旋翼模式转换到固定翼模式。
前向转换推式/拉式电机的油门变化速率，决定油门逐渐提升到目标值（由 `VT_F_TRANS_THR` 定义）所用的时间。

值为 0 时，将立即给出转换油门指令值。
默认变化速率为 0.33，意味着提升到 100% 油门需要 3 秒。
如果希望油门提升过程更平滑，可以减小该值。

请注意，一旦油门渐升阶段结束，油门将达到目标设置，并保持该值直到（理想情况下）达到转换速度。

#### 空速混控

参数：[VT_ARSP_BLEND](../advanced_config/parameter_reference.md#VT_ARSP_BLEND)

默认情况下，随着空速接近转换速度，多旋翼姿态控制会逐渐减弱，固定翼控制会持续增强，直到完成转换。

将该参数设置为 0 可禁用混控：在转换发生之前保持完整的多旋翼控制，同时固定翼控制保持为零。

#### 转换空速

参数：[VT_ARSP_TRANS](../advanced_config/parameter_reference.md#VT_ARSP_TRANS)

当飞行器达到此空速时，将触发从多旋翼模式到固定翼模式的转换。
正确校准空速传感器至关重要。
选择的空速还必须明显高于机架的失速速度（检查 `FW_AIRSPD_MIN`），因为系统目前不会对此进行检查。

#### 开环转换时间

参数：[VT_F_TR_OL_TM](../advanced_config/parameter_reference.md#VT_F_TR_OL_TM)

该参数指定在没有空速反馈（例如未安装空速传感器）时，前向转换的持续时间（秒）。
该值应确保飞行器能达到足够高的空速以完成转换，例如空速应超过 [VT_ARSP_TRANS](../advanced_config/parameter_reference.md#VT_ARSP_TRANS)。

#### 转换超时

[VT_TRANS_TIMEOUT](../advanced_config/parameter_reference.md#VT_TRANS_TIMEOUT)

该参数指定前向转换持续时间的上限。如果超过此时间飞行器仍未达到转换空速，转换将中止，并触发一次 [Quad-chute](../config/safety.md#quad-chute-failsafe) 事件。

:::note
此外，如果装有空速传感器，在开环转换时间 [VT_F_TR_OL_TM](../advanced_config/parameter_reference.md#VT_F_TR_OL_TM) 结束后，空速仍未达到 [VT_ARSP_BLEND](../advanced_config/parameter_reference.md#VT_ARSP_BLEND)，转换也会中止。此项检查用于避免空速传感器故障时飞行器速度过高。
:::

### 转换操作提示

如前所述，请确保多旋翼模式已充分调好。
如果转换过程中出现问题，你会切回该模式，因此切回过程应当相当平稳。

飞行前，应针对多旋翼、转换、固定翼这三个阶段分别制定应急计划，明确在每个阶段发生问题时应采取什么措施。

电池电量：应留出足够余量，确保飞行结束时能够转换到多旋翼模式并着陆。
不要让电池电量过低，因为以多旋翼模式着陆需要更多功率。
请采取保守策略。

#### 转换：准备工作

确保飞行器距地面至少 20 米，并有足够空间完成转换。
切换到固定翼模式时，VTOL 可能会掉高，尤其是在空速不足的情况下。

应尽可能迎风转换，否则飞行器在完成转换前会飞离你更远。

开始转换前，确保 VTOL 已处于稳定悬停状态。

#### 转换：多旋翼到固定翼（前向转换）

开始转换。
飞行器应在 50 至 100 米内完成转换。
如果未能完成，或飞行状态不稳定，请中止转换（见下文），然后着陆；也可以悬停返回起始位置后再着陆。
尝试增大[转换油门](#转换油门)（`VT_F_TRANS_THR`）值。
如果未使用空速传感器，也可考虑减小转换持续时间（`VT_F_TRANS_DUR`）。
如果使用空速传感器，可考虑降低转换空速，但必须使其明显高于失速速度。

发现转换完成后，应立即准备应对高度损失，这可能包括快速增加油门。

:::warning
以下功能已经讨论过，但尚未实现：

- 转换完成后，多旋翼电机将停止；假设飞行器处于手动模式，在你移动油门摇杆之前，推式/拉式电机油门将保持在 `VT_F_TRANS_THR` 水平。
  :::

#### 转换：固定翼到多旋翼（后向转换）

切回多旋翼模式时，让飞行器沿平直航线进近并降低速度。拨动转换开关后，飞行器会启动多旋翼电机并立即停止推式/拉式螺旋桨，通常可实现较平稳的滑翔转换。

请注意，转换瞬间的油门值将决定多旋翼在开关切换时获得的推力。
由于机翼此时仍在产生升力，你会有充足时间调整油门，以达到或保持悬停。

有关后向转换的高级调参，请参阅[后向转换调参指南](vtol_back_transition_tuning_zh.md)。

#### 中止转换

了解在转换过程中撤销转换指令时飞行器的行为非常重要。

从**多旋翼转换到固定翼**时（转换开关处于开启/固定翼位置），如果在转换完成前将开关拨回（关闭/多旋翼位置），飞行器会立即返回多旋翼模式。

对于此类 VTOL，从**固定翼转换到多旋翼**时，开关切换会立即生效，因此与倾转旋翼 VTOL 不同，实际上没有中途撤销的选项。
如果想重新进入固定翼模式，则需要再次完成整个转换过程。
如果飞行器仍保持较高速度，这一过程应该会很快完成。
